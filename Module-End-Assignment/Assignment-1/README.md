# Module End Assignment 1 – Data Cleaning, Analysis & Visualization with Excel

## Overview

This project demonstrates data cleaning, transformation, analysis, and visualization techniques using Microsoft Excel. The e-commerce dataset was cleaned and validated, multiple tables were combined using XLOOKUP, descriptive statistics and PivotTables were created, and an interactive dashboard was developed to analyze sales, products, customers, regions, payment types, and sales trends.

## Tasks Performed

- Data Entry and Table Organization
- Data Cleaning and Validation
- Handling Missing and Inconsistent Data
- Duplicate and Consistency Checks
- Data Transformation using XLOOKUP
- KPI and Sales Analysis
- Product Analysis and Top 10 Products
- Customer and Loyalty Level Analysis
- Monthly and Yearly Sales Analysis
- Descriptive Statistics
- PivotTable Analysis
- PivotChart Creation
- Bar, Column, and Pie Chart Visualization
- Interactive Dashboard with Slicers
- Sales Trend Analysis

## Excel Functions Used

- SUM
- IF
- COUNTIF
- AVERAGE
- TEXT
- XLOOKUP
