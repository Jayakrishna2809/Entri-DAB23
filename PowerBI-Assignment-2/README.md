## DAX Calculations

The assignment includes the following calculated columns and measures:

### Calculated Columns

- **Category Type** – combines Category and Sub-Category to create a combined classification.
- **Revenue per Order** – calculates revenue using Amount and Quantity.
- **Sales Category** – classifies sales as Above Average or Below Average based on the average Amount.

### Measures

- **Order Count** – counts distinct Order IDs.
- **Average Profit in Delhi** – calculates the average profit for orders associated with Delhi.
- **YTD Sales** – calculates year-to-date sales using the order date.
