# Excel Assignment 2 – Data Cleaning and Transformation

## Overview
This project demonstrates data cleaning and transformation techniques in Microsoft Excel. The dataset was cleaned by handling missing values, correcting inconsistent text, removing duplicate records, splitting and merging columns, applying number formatting, and using conditional formatting to improve data quality and visualization.

## Tasks Performed
- Handling Missing Values
- Find and Replace Corrections
- Removing Duplicates
- Product Name Standardization (PROPER Function)
- Manufacturing Date Extraction
- Country Code Extraction
- Product Brand Creation (Concatenation)
- Number Formatting
- Conditional Formatting

## Excel Functions Used
- PROPER
- LEFT
- RIGHT
- DATE
- MONTH
- DATEVALUE
- Concatenation (&)
